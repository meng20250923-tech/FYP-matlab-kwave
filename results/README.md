# Curated results

This directory contains only small, final artefacts used to verify the experiments reported in the dissertation.

- `tables/` contains compact CSV summaries of the final numerical results.
- `figures/` contains selected figures derived from those summaries.

Raw datasets, HDF5 shards, model checkpoints, per-sample predictions, complete reconstruction arrays, logs, and temporary outputs are intentionally excluded from Git because of their size. These artefacts can be regenerated using the commands documented in the main project README.
